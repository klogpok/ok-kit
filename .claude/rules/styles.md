# Styles and tokens

- Stylelint allows only logical `text-align` values (`start`, `end`, `center`).
- App SCSS uses `@use 'ui-kit/styles' as ui` with `stylePreprocessorOptions.includePaths: ["projects"]`.
- `styles/ui-kit-embed.scss` (loaded by `<ui-embed-styles />`) is tokens + layout classes only: no `_base`, no `_typography`. Its `_tokens-embed.scss` is generated by `tokens/build-tokens.mts` without the `prefers-color-scheme: dark` block; change the generator, never the file. Keep its `@use`s relative: a copy of the kit compiles it without `includePaths`.
- The kit is embedded in host apps whose global CSS (Bootstrap 4.6 reboot) must not bend it, and `pnpm test-host-css` fails when it does. In a new component: the root (`:host`, or the root class of an unencapsulated component) and every overlay panel set `text-align: start` (a native `button` root keeps `center`); every `label` sets `margin: 0` and its `display`; every `svg`/`img` sets `vertical-align` (`baseline`, the initial value, when nothing else is meant); native inputs and icon-only buttons set `font: inherit`. `color` and `letter-spacing` are inherited from the host where a component does not set them, on purpose.
